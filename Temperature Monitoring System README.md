# 🌡️ Sensor-Based Temperature Monitoring System

## 📌 CodeAlpha IoT Internship – Task 2

This project demonstrates a **sensor-based temperature monitoring system** using an **Arduino Uno**, a **temperature sensor**, and an **LED**.

The circuit is simulated using **Tinkercad Circuits**.

## 🎯 Objective

The main objective of this task is to:

- Interface a temperature sensor with Arduino Uno.
- Read temperature values from the sensor.
- Monitor the temperature continuously.
- Control an LED based on the temperature condition.
- Understand basic sensor-based automation.

## 🛠️ Components Used

- Arduino Uno
- Temperature Sensor (TMP)
- LED
- Resistor
- Connecting wires
- Tinkercad Circuits Simulator

## ⚙️ Working Principle

The temperature sensor detects the surrounding temperature and provides an electrical signal to the Arduino.

The Arduino reads the sensor value and checks the temperature condition.
